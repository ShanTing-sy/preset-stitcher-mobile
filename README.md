# 奇美拉·预设缝合台 · 手机版

「[奇美拉·预设缝合台](https://github.com/ShanTing-sy/preset-stitcher)」的**手机适配版**。

功能与桌面版**完全一致**（缝合 / 变量 / 正则 / AI 助手 / 条目编辑，一个不少），差别只在布局：

**左上角切换「预设缝合 / 正则缝合」，下面一行是当前模式的全部页签；内容单列堆叠，每页最多上下两块。**

桌面版是三栏并排，在手机竖屏上会挤成一团；这个版本按 iOS 竖屏标准（844×390pt）重排。

---

## 安装

### 方式一：填 Git URL（推荐）

1. 打开酒馆 → **扩展** → **安装扩展**
2. 填本仓库地址：

   ```
   https://github.com/ShanTing-sy/preset-stitcher-mobile
   ```

3. 点安装 → **刷新页面（F5）**
4. 魔法棒菜单里会出现「**预设缝合·手机**」

> ⚠️ 如果之前手动装过同名文件夹，酒馆会报「目录已存在」。先删掉
> `data/<你的用户名>/extensions/preset-stitcher-mobile/` 再装。

### 方式二：手动放置

把本仓库的文件放进：

```
<酒馆目录>/data/<你的用户名>/extensions/preset-stitcher-mobile/
```

然后刷新页面。

### 六个页签（预设缝合模式）

| 页签 | 上半 | 下半 |
|---|---|---|
| **预设** | 导入/管理源预设（点 ☆ 设骨架） | 全局参数 |
| **条目** | 待选的源条目 | 已缝合的目标条目 |
| **变量** | 变量树杈图 | 效果预览 |
| **AI** | AI 助手：抓取、改写、注入参照、生成结果 | — |
| **比对** | 原条目（上）/ AI 版本（下） | — |
| **编辑** | 条目编辑器 | — |

**「条目」页**是缝合的主战场：上半从源预设里挑，点一下就进下半的目标列表——缝合动作就是「从上往下拿」。

**「AI」页**的操作与结果在一起：AI 助手面板底部就是**生成结果列表**，点一条直接进「比对」页看新旧对照。待确认条数会显示在**「AI」页签的徽标**上，所以在别的页签也能看到有没有待办。

**「比对」页**是查看 AI 结果的地方：上半旧条目、下半 AI 版本，底部三个按钮 —— **写入 / 重新生成 / 放弃**。

### 左上角切换模式

点左上角的「🧩 **预设**」可以切到「**正则缝合**」，**整套页签会跟着换**（用不上的页签不占位）：

| 页签 | 内容 |
|---|---|
| **预设** | 同上（槽位与全局参数两种模式共用） |
| **正则** | 上半待选正则 / 下半目标正则，可拖拽调序 |
| **AI** | AI 助手（正则轨） |
| **正则编辑** | 正则编辑器 |

### 每页上下两块之间的那根线可以拖

「预设 / 条目 / 正则」三页的中间都有一根分隔线，按住上下拖可以调整两块的高度。
**触屏设备上这根线的热区会自动加宽到 20pt**，手指很好按。

点顶部槽位名会打开**槽位菜单**：切换 / 新建 / 重命名 / 同步到酒馆 / 导入为素材 / 删除 / 清空全部。

### 悬浮球：够不到顶栏时用这个切页

面板里有一颗 44pt 的悬浮球，默认停在**左下角**（在底部操作条上方，不会压住「骨架」那行字）。

| 动作 | 结果 |
|---|---|
| 按住拖动 | 球跟着手指走，松手后吸附到最近的左 / 右边缘 |
| 轻点一下 | 展开 / 收起页签目录 |
| 点目录项 | 切到该页签 |
| 点别处 | 收起目录 |

目录里列的就是顶部的全部页签（带数量徽标、当前页高亮），**内容与顶部页签栏永远一致** ——
切到「正则缝合」模式时，两边会一起变成 4 项。

球的位置会被记住：关掉面板再打开，它还在你放的地方。

> 球只存在于面板内部。关掉面板它就一起消失，不会往酒馆主页面上留任何东西，
> 桌面版也完全感知不到它的存在（位置存在手机版专属的设置键里，不写进两边共用的工作区数据）。

### 尺寸基准

| 元素 | 尺寸 |
|---|---|
| 导航栏 | 44pt |
| 页签栏 | 50pt |
| 底部操作条 | 50pt |
| 横向页边距 | 16pt |
| 触控目标 | ≥ 44×44pt |
| 悬浮球 | 44×44pt，停靠时距屏幕边缘 12pt |
| 其余间距 | 一律 4 的倍数 |

顶部和底部会自动避开刘海、状态栏、悬浮地址栏与 Home 指示条。
避让量是在酒馆页面里实测后递进来的（见下方 v1.1.2），无刘海设备则为 0。

## 与桌面版的关系

- **两个独立的扩展**，可以同时装，互不干扰
- **共用同一份工作区数据**——所以可以手机上缝一半、电脑上接着改
- 功能一模一样，只是布局不同

### v1.1.2：新增悬浮球 + 顶栏不再被状态栏 / 地址栏压住

#### 新增悬浮球：切页签不用再够屏幕顶端

手机竖屏握持时，大拇指其实够不到最上面那条页签栏。现在面板里多了一颗**悬浮球**：

- **拖动**它可以停在屏幕任意位置，松手后吸附到最近的一侧（初始落在**左下角**）
- **点一下**它展开一个小目录，列出全部页签（带数量徽标），点哪一项就切到哪一页
- 目录内容与顶部页签栏**逐项一致**：改模式（预设 / 正则）时两边一起变，不会对不上
- 位置会记住，关掉面板再打开还在你放的地方

> 球只活在面板里 —— 面板关掉它就一起消失，不会往酒馆主页面上留东西。

#### 顶栏被状态栏 / 地址栏压住 —— 已修

修的是手机上一个很别扭的老毛病：**打开面板后，最上面那条导航栏（模式切换、槽位、主题、关闭）怎么都露不出来，
被手机的状态栏或悬浮地址栏盖住一截**。

原因是面板铺满了「整个布局视口」，而那个视口向上一直延伸到系统 UI 底下 —— 但面板自己却以为不需要留白。三处一起修：

- **安全区改成从酒馆页面量了再递进来**。面板跑在 iframe 里，它自己量 `env(safe-area-inset-*)` 永远是 0
  （iframe 是独立文档，没有 `viewport-fit=cover`）；现在改成在酒馆页面里量出真实刘海高度，再用 CSS 变量递给面板。
- **面板改为钉在「真正看得见的那块」上**（`visualViewport`），不再是 `100vh`。
  `100vh` 取的是地址栏收起时的最大高度，永远偏大。改完之后**软键盘弹起时面板会跟着变矮**，
  底部操作条不再被键盘顶出屏幕。
- **打开面板期间把酒馆页面钉住、并给面板加了滚动隔离**。酒馆的 `html` 上有 `-webkit-transform`
  （它用来防 Chrome 毛玻璃闪烁的），那会让 `position: fixed` 变成相对文档定位 ——
  酒馆页面一滚，面板就会被一起顶走。

> 布局本身没有变化：导航栏 44pt、页签栏 50pt、操作条 50pt、页边距 16pt 全部照旧。
> 只是面板终于被钉在了它该在的位置上，各页签里的长内容照常在自己的区域内滚动。

### v1.1.1：按 iOS 标准重排布局

- **页签从「两层五个」改成「一层六个」**：AI 助手 / 条目比对 / 条目编辑器 从二级子页签提升为一级页签，砍掉了多余的一层导航
- **左上角新增模式切换**：一键在「预设缝合 / 正则缝合」之间切换，页签栏整套跟着换
- **「条目」页改为源（上）/ 目标（下）上下堆叠**，缝合动作变成「从上往下拿」
- **AI 生成结果并入 AI 页签**（AI 助手面板自带结果列表），待确认条数显示在「AI」页签徽标上
- **尺寸全面对齐 iOS 竖屏标准**：导航栏 44pt、页签栏 50pt、操作条 50pt、页边距 16pt、触控目标 ≥44pt
- 顶部 / 底部自动避开刘海与 Home 指示条
- 拖动分隔线的热区在触屏设备上从 8pt 加宽到 20pt

### v1.1.0 起手机版也有的新功能

- **变量树杈图**：一条声明连到它的所有来源，连线零交叉；值行显示条目正文首行，点开看全文
- **✨ AI 解析**（在变量页）：让 AI 通读选中的预设，把「没写 `setvar` 宏、但实际在给某个变量赋值」的条目也找出来。结果标出与现有树的差异，可选**查漏补缺**或**覆盖整棵树**
- **条目比对**：AI 生成的结果不直接覆盖，先在新旧对照里确认。底部 **写入 / 重新生成 / 放弃** 三个按钮
- **AI 助手**：底部改成对话框（发送 / 暂停 / 重说）；生成结果存在本地，切页签不会丢；注入参照**默认全部注入**，可逐条移除，也能从其他源预设直接注入
- **点任何条目都能编辑**：目标条目、AI 生成结果、源预设里的条目，同一个编辑器
- **单击条目 = 打开编辑**，行尾的 `＋` 才是加入 / 移出目标

## 已知限制

与桌面版相同：

| 限制 | 说明 |
|---|---|
| 只支持对话补全格式预设 | 即酒馆里 `openai` 那一组 |
| 生成中无法中途打断 | 酒馆原生 `generateRaw` 的限制。点「停止」会在当前这一条完成后生效 |
| 预设正则需授权 | 酒馆要求预设正则在「扩展 → 正则」里被允许才生效。插件会自动加白名单 |
| 正则部分字段会丢 | 酒馆会把「替换宏」重置为 0，且不保留「推理」作用范围。插件会检出提示 |

## 更新

```bash
# 1. 重新构建（源码工程目录）
node build-css.mjs
npx --yes pnpm@10 exec webpack --config webpack.extension.mjs --mode production

# 2. 把 dist/预设缝合助手手机版扩展/ 下的 index.js、index.js.map、
#    index.js.LICENSE.txt 一起复制到本仓库根目录
#    （LICENSE.txt 是 Vue / Pinia 的许可声明，产物首行就指着它，别漏）

# 3. manifest.json 里两处版本号一起 +1
#    "js": "index.js?ver=1.1.2"
#    "version": "1.1.2"

# 4. git add . && git commit -m "v1.1.2" && git push
```

> ⚠️ **不要直接改酒馆安装目录里的文件**。那是 git 仓库，手动改会留下本地修改，
> 之后点「更新」时会因「本地改动会被覆盖」而拉取失败，报
> `Extension update failed / Internal Server Error`。
> 要改就改本仓库，再让酒馆更新。

版本号很重要：酒馆用 `<script type="module">` 加载扩展，浏览器会强缓存，
`?ver=` 变了才会拉新文件。
